## Installing ```curl```

### On a Mac or Linux Distro

Assuming you have already installed homebrew, you can install ```curl``` from a Terminal with the command:

```bash
brew install curl
```

Be sure to note the instructions after installation about adding ```curl``` to your path. Namely:

```bash
echo 'export PATH="/opt/homebrew/opt/curl/bin:$PATH"' >> ~/.zshrc
```
